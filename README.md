# 📘 Machine Learning Lab – Index  
**ML Lab Experiments**

This repository contains all Machine Learning Lab experiments, organized by topic.  
Each experiment folder includes Python scripts (`assignmentX.py`) and a detailed `README.md` documenting objectives, code, outputs, and conclusions.

---

## 📂 Experiments Overview

### 🔹 [Experiment 1 – Python and ML Environment Basics](Experiment_1/README.md)
- **Assignment 1:** Create a NumPy array containing the internal marks of 10 students Calculate and print the mean, median, standard deviation, maximum, and minimum values.  

- **Assignment 2:** Construct a DataFrame containing the following columns: Student Name, Roll Number, Marks, and Attendance. Filter and display only the records of students who have scored above 80 marks  

- **Assignment 3:** Write a script to add a new dynamically calculated column named Grade to the DataFrame based on the Marks column (e.g., ¿90 is ’A’, 80-89 is ’B’, etc.).

---

### 🔹 [Experiment 2 – Dataset Loading, Exploration, and Visualization](Experiment_2/README.md)
- **Assignment 1:** Load and perform a complete **EDA** on the Wine dataset available in **Scikit-learn**.

- **Assignment 2:** Plot **Boxplots** for all numerical attributes in the Wine dataset to visually identify any potential outliers.

- **Assignment 3:** Generate a correlation heatmap (using **Seaborn’s heatmap**) and identify the pair of features that exhibit the strongest positive correlation.

---

### 🔹 [Experiment 3 – Data Preprocessing](Experiment_3/README.md)
- **Assignment 1:** Create and preprocess a synthetic dataset containing the features: **Age, Salary, Department, and Years of Experience**. Inject missing values deliberately.

- **Assignment 2:** Modify the pipeline code to apply **MinMaxScaler** instead of **StandardScaler**.

- **Assignment 3:** Compare and document the effect of **StandardScaler vs MinMaxScaler** by printing the transformed arrays and observing their numerical ranges.

---

### 🔹 [Experiment 4 – Linear Regression](Experiment_4/README.md)
- **Assignment 1:** Predict house prices using **Area**.  

- **Assignment 2:** Implement **Multiple Linear Regression** (Area + Bedrooms).  

- **Assignment 3:** Apply **Polynomial Regression** and compare R² scores.

---

### 🔹 [Experiment 5 – Logistic Regression](Experiment_5/README.md)
- **Assignment 1:** Predict **Pass/Fail** based on study hours & attendance.  

- **Assignment 2:** Modify **decision thresholds** (0.3, 0.5, 0.7) and compare Precision/Recall.  

- **Assignment 3:** Plot **ROC curve** and calculate **AUC score**.
